# 🔐 CryptoProSigningOnline

> Современный веб-сервис для подписания документов электронной цифровой подписью с использованием КриптоПро

## 📋 Описание

**CryptoProSigningOnline** - это веб-приложение для создания электронных цифровых подписей документов непосредственно в браузере. Сервис использует КриптоПро ЭЦП Browser plug-in для работы с российскими криптографическими стандартами и квалифицированными сертификатами электронной подписи.

### ✨ Основные возможности

- 🔒 **Безопасное подписание** - все операции выполняются локально в браузере
- 📄 **Любые форматы файлов** - поддержка PDF, DOCX, XLSX, и других форматов
- 🎯 **Отсоединенная подпись** - создание файлов `.sig` отдельно от документа
- ⚡ **Массовое подписание** - подпись нескольких документов подряд без перезагрузки
- 🌐 **Современный интерфейс** - адаптивный дизайн для всех устройств
- 🔄 **Автоматическое сохранение** - подпись сохраняется автоматически после создания
- 📊 **Счетчик документов** - отслеживание количества подписанных документов

## 🚀 Быстрый старт

### Требования

Для работы сервиса необходимо:

1. **КриптоПро ЭЦП Browser plug-in** (версия 2.0 или выше)
   - Скачать: [cryptopro.ru](https://www.cryptopro.ru/products/cades/plugin)
   - Поддерживаемые браузеры: Chrome, Firefox, Edge, Opera

2. **Квалифицированный сертификат ЭП** с установленным приватным ключом

3. **Современный браузер** с поддержкой:
   - File System Access API (для выбора места сохранения)
   - JavaScript ES6+

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/qdpops/CryptoProSigningOnline.git
cd CryptoProSigningOnline
```

2. Для работы требуется веб сервер с защищенным соединением

## 📖 Использование

### Шаг 1: Выбор сертификата

После загрузки плагина выберите сертификат из списка доступных. Система автоматически отобразит:
- Владельца сертификата
- Срок действия
- Статус валидности

### Шаг 2: Настройка параметров

Выберите параметры подписи:
- ✅ **Метка времени (TSA)** - добавляет штамп времени к подписи
- ✅ **Отсоединенная подпись** - создает отдельный файл `.sig` (рекомендуется)
- **Тип подписи**:
  - CAdES-BES (базовая)
  - CAdES-X Long Type 1 (расширенная)
  - CAdES-T (с меткой времени)

### Шаг 3: Выбор документа

Загрузите документ одним из способов:
- Перетащите файл в область загрузки (Drag & Drop)
- Кликните в области загрузки для выбора файла

### Шаг 4: Подписание

Нажмите кнопку **"Подписать документ"**. Файл подписи автоматически:
1. Создастся в формате `.sig`
2. Будет предложен для сохранения рядом с исходным документом
3. Отобразится информация о результате

### Шаг 5: Продолжение работы

Нажмите **"Подписать еще"** для подписания следующего документа без перезагрузки страницы.

## 🔧 Конфигурация

### Типы подписи

```javascript
// CAdES-BES - базовая электронная подпись
signatureType: 1

// CAdES-X Long Type 1 - расширенная подпись
signatureType: 2

// CAdES-T - подпись с меткой времени
signatureType: 3
```

### TSA сервер

По умолчанию используется сервер меток времени КриптоПро:
```javascript
TSAAddress: "http://cryptopro.ru/tsp/"
```

Можно изменить на собственный TSA сервер в коде.

## 🔐 Безопасность

### Приватность данных

- ✅ Все операции выполняются **локально в браузере**
- ✅ Документы **не отправляются на сервер**
- ✅ Приватные ключи **остаются на устройстве**
- ✅ Нет сбора персональных данных

### Требования безопасности

1. Используйте только доверенные сертификаты
2. Проверяйте срок действия сертификата
3. Не передавайте приватные ключи третьим лицам
4. Храните подписанные документы в безопасном месте

## 🐛 Известные проблемы

### Совместимость браузеров

| Браузер | Поддержка | File System Access API |
|---------|-----------|------------------------|
| Chrome  | ✅ Полная | ✅ Да                  |
| Edge    | ✅ Полная | ✅ Да                  |
| Opera   | ✅ Полная | ✅ Да                  |
| Firefox | ⚠️ Базовая | ❌ Нет (fallback)     |
| Safari  | ⚠️ Базовая | ❌ Нет (fallback)     |

### Ограничения

- Размер файла ограничен памятью браузера (обычно до 2GB)
- TSA сервер может быть недоступен (используйте опцию отключения)
- Некоторые корпоративные файрволы блокируют TSA запросы
